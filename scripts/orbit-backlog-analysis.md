## B. 개선해야 할 항목 (우선순위)

### P0 — 원장/현장 즉시 막힘
1. **근태관리 메뉴/화면이 안 보임** (배성준 대표원장)
2. **출결 체크에 조퇴 버튼 추가**
3. **월간 리포트: 「수학만」필터인데 영어도 출력**
4. **월간평가 입력 시 주간평가가 리포트에 안 보임** (둘 다 보이게)
5. **학생목록에서 사라짐** — 조수현(현일중3), 신규상담에 영어 추가 후 `학생관리-학생목록`에서 소실 / 성장리포트 쪽에는 남음

### P1 — 교재·점수 입력
6. **교재 마스터**: 등록 목록 표시 + 수정/삭제
7. **교재 배부 현황**: 잘못 입력 행 삭제
8. **교재 배부 현황**: 팀장급 이상 전체 캠퍼스 조회
9. **점수 부분 저장**: 과목 1개만 있어도 저장 / 전부 채워야 「입력 완료」
10. **학부모 연락처**: 부·모 구분·최대 2개 / **하나만 있어도 저장**
11. **형제 연동** 기능
12. **지필평가 관리**: 고2 수학 → 미적분·기하 옵션
13. **지필평가 회차**: 학교별 기간 겹쳐도 생성 가능  
    (`school_exam_scores_id_school_year_semester_exam_type_key` 충돌)
14. **지필 점수**: 입력한 강사만 보임 → 전체 강사 공유
15. **팀장급+**: 캠프(캠) 전체 학생 점수 입력 여부 확인

### P2 — 상담·리포트·시간표
16. **신규상담관리**: 재원생 과목 추가 설정
17. **시험대비 보강 등록**: 같은 날짜 여러 명 일괄 등록
18. **퇴원 보고서**: 강사 작성 권한 개방 (일부 열림) + **직급4 결재 라인** 수정  
    (현재 팀장→분원장만이라 직급4가 결재 UI 없음)
19. **레포트 이미지**: 교사 코멘트 잘림
20. **인동캠 개별 시간표 미표시** — 이서현·임예지 수 13:40 조기등원

## C. 러버블에 바로 넣을 지시서 (P0 묶음)

아래를 오르빗 Lovable 채팅에 붙여넣기.

```
오르빗 P0 버그/기능 수정. UI 과디자인 금지. 기존 디자인 시스템 유지.
배포 후 각 항목 확인 방법까지 짧게 보고.

━━━━━━━━━━━━━━━━━━━━
1) 근태관리 안 보임 (원장 보고)
- 메뉴/라우트/권한에서 「근태관리」가 숨겨지거나 롤에 빠진 이유 찾기
- 원장·팀장·강사 각각 노출 규칙 확인 후, 원래 보여야 할 롤에는 다시 노출
- 권한 없으면 「권한 없음」안내. 메뉴 자체가 사라지지 않게(또는 의도적 숨김이면 문서화)

2) 출결 체크 — 조퇴 버튼
- 출결 체크 화면에 「조퇴」상태/버튼 추가 (출석·결석·지각과 동급)
- 저장·리포트·통계에 조퇴가 반영되게
- 기존 출석 데이터 마이그레이션 불필요하면 생략

3) 월간 리포트 「수학만」필터
- 출력/미리보기에서 과목 필터가 영어·수학을 같이 그리면 안 됨
- 필터=수학 → 과목/강의/테스트/총평 모두 수학만
- 필터=영어 → 영어만 / 전체 → 둘 다
- 구자훈 2024.09 월간리포트 재현 케이스 기준으로 검증

4) 월간평가 + 주간평가 동시 표시
- 월간평가 점수가 있어도 주간평가가 리포트에서 사라지지 않게
- 둘 다 있으면면 둘 다 출력

5) 학생목록 소실 (조수현 현일중3)
- 신규상담에 과목(영어) 추가 후 students 목록 쿼리/필터/상태값이 재원생을 제외하는지 점검
- 성장리포트 목록에는 보이는데 학생관리 목록에만 없으면 학생관리 쪽 필터/조인 버그
- 상담·수강과목 추가가 enrolled 상태나 campus/subject 필터를 깨지 않게 수정
- 수정 후 조수현이 학생관리-학생목록에 다시 보이게

인증·다른 메뉴 대규모 리팩터 금지. 변경 파일과 배포 여부만 보고.
```
